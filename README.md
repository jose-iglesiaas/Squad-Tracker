# SquadTracker

Welcome to my very first PHP application! 

SquadTracker is a simple web-based training log designed for sports coaches. It allows users to register player attendance, track training equipment, define the session type, and add observations. 

**Note on complexity:** This is a beginner project. There is no database or complex backend architecture yet, as I am currently learning the core concepts of PHP. 

The application's interface and outputs are entirely in Spanish.

## Features
- Form data processing using PHP (`$_POST`, `isset`, `empty`).
- Array handling for multiple checkbox selections (players and equipment).
- Dynamic UI rendering based on user inputs.
- Clean and semantic HTML5 structure (Styling pending).

## Built With
- **Frontend:** HTML5, CSS
- **Backend:** PHP 8 (No DB)
